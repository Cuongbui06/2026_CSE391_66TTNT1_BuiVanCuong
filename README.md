## 📖 Giới thiệu
**CSE391 – Web Programming** là môn học cung cấp các kiến thức nền tảng và thực hành về phát triển ứng dụng web, bao gồm cả **Front-end** và **Back-end**.  
Môn học giúp sinh viên làm quen với cách xây dựng website từ cơ bản đến nâng cao và rèn luyện tư duy lập trình web thực tế.

---

## 🧠 Nội dung chính
- HTML5, CSS3  
- JavaScript cơ bản  
- Responsive Web Design  
- Git & GitHub  
- Framework và thư viện hỗ trợ (Bootstrap, v.v.)  
- Kiến thức cơ bản về Web Server và Backend  

---

## 🎯 Mục tiêu môn học
- Hiểu cấu trúc và nguyên lý hoạt động của website  
- Xây dựng được giao diện web hoàn chỉnh  
- Biết cách quản lý mã nguồn bằng Git/GitHub  
- Rèn luyện tư duy lập trình web thực tế
